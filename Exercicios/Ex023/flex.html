O que é Flexbox?

Um modelo de layout CSS para criar designs flexíveis e responsivos

Conceito Básico

Flexbox é um módulo de layout do CSS que permite organizar elementos em um container de maneira previsível, mesmo quando seus tamanhos são dinâmicos.

O modelo Flexbox consiste em:

  • Container Flex: Elemento pai com display: flex
  • Itens Flex: Elementos filhos diretos do container

Vantagens do Flexbox

  • Facilita o alinhamento e distribuição de espaço entre itens
  • Permite que os itens se ajustem para preencher o espaço disponível
  • Simplifica a criação de layouts responsivos
  • Oferece melhor controle sobre o alinhamento vertical

Propriedades do Container

flex-direction: Define a direção dos itens (linha ou coluna)

justify-content: Alinha os itens ao longo do eixo principal

align-items: Alinha os itens ao longo do eixo transversal

flex-wrap: Permite que os itens quebrem para a próxima linha
